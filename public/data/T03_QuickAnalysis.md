## Quick Analysis

**Topic:** Extracting key concepts for a single document with 1 to 3 Large Language Models.

**Description:** This page provides a description and steps for executing a single-document Quick Analysis. 

**Steps:**

1. Enter the domain that describes the subject area of the document.
2. Select the plain-text (.txt) reference document that you want to analyse.
3. Select one or more Large Language Models to perform the analysis.
4. Specify the target ontology that is being enhanced.
5. Optionally specify related ontologies that should be considered during the analysis.
6. Review the analysis prompt and modify it if appropriate.
7. Select **Submit** to begin the analysis.
8. When processing is complete, select **Display Results** to review the identified terms.
